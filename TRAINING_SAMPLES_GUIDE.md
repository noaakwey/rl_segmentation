# 📊 Руководство по эталонам для обучения

## Сколько эталонов нужно и как их расположить

Подробное руководство по количеству обучающих данных и стратегиям их пространственного распределения для задач сегментации пашни и оврагов.

---

## 📌 Краткий ответ

### Для пашни (cropland):
- **Минимум:** 50-100 полей (5-10 км²)
- **Оптимум:** 200-500 полей (20-50 км²)
- **Идеально:** 1000+ полей (100+ км²)

### Для оврагов (permanent gully):
- **Минимум:** 30-50 оврагов (1-2 км линейной длины)
- **Оптимум:** 100-200 оврагов (5-10 км)
- **Идеально:** 500+ оврагов (20+ км)

### Пространственное распределение:
- ✅ **Стратифицированное** по ландшафтам
- ✅ **Репрезентативное** разнообразие форм/размеров
- ✅ **Распределенное** по климатическим зонам
- ❌ **НЕ кластерное** (избегать скопления в одном месте)

### 2.2 Специфика оврагов vs пашни

| Характеристика | Пашня | Овраги |
|---------------|-------|--------|
| **Тип объекта** | Площадной | Линейный |
| **Размер** | 0.5-50 га | 50-500 м длина × 3-20 м ширина |
| **Контраст** | Высокий | Низкий-средний |
| **Форма** | Регулярная-неправильная | Извилистая, ветвящаяся |
| **Сложность** | Средняя | **Высокая** ⚠️ |
| **Нужно эталонов** | 200-500 полей | 100-200 оврагов |
| **Точность** | 0.85-0.92 | 0.75-0.85 (**сложнее!**) |

**Почему овраги сложнее:**
1. ⚠️ **Малый размер:** узкие линейные объекты (3-20 м) трудно выделить на Sentinel-2 (10 м)
2. ⚠️ **Низкий контраст:** овраги часто зарастают, сливаются с окружением
3. ⚠️ **Сложная форма:** ветвящиеся структуры, неоднородная ширина
4. ⚠️ **Частичная видимость:** затенение, растительность, сезонные изменения
5. ⚠️ **Разнообразие типов:** активные / стабилизированные / залеченные

## 3. Использование Active Learning для оптимизации

**Ключевая идея:** Начните с минимума, затем **умно добавляйте** эталоны!

### 3.1 Стратегия активного обучения

```python

from src.advanced_agent import AdvancedRLAgent

# Шаг 1: Начать с минимальной разметки
initial_samples = {

}

# Шаг 2: Обучить начальную модель
agent = AdvancedRLAgent(in_channels=12, use_active_learning=True)
agent.train(initial_samples, num_epochs=50)

# Шаг 3: Найти наиболее неопределенные области
selector = ActiveLearningSelector()
uncertain_regions = selector.select_for_annotation(

    k=50,  # Добавить 50 новых эталонов
    strategy='combined'  # uncertainty + diversity

# Шаг 4: Разметить ТОЛЬКО выбранные регионы (экономия времени!)
# Шаг 5: Переобучить с новыми данными
# Шаг 6: Повторить до достижения целевой точности
```

### 4.2 Чек-лист качества разметки

#### ✅ Пространственное распределение
- [ ] Эталоны покрывают 3+ ландшафтных зон
- [ ] Минимальное расстояние > 500м между объектами
- [ ] Нет кластеров (все эталоны в одном месте)
- [ ] Репрезентативное покрытие территории

#### ✅ Разнообразие
- [ ] Малые + средние + крупные объекты
- [ ] Регулярные + неправильные формы
- [ ] Различные спектральные характеристики
- [ ] Различные контексты (окружение)

#### ✅ Качество границ
- [ ] Точная оцифровка границ (± 1-2 пикселя)
- [ ] Согласованность между разметчиками
- [ ] Проверка на пространственных данных высокого разрешения
- [ ] Атрибутивная информация (тип, размер, дата)

#### ✅ Валидация
- [ ] Отдельный validation set (20-30% данных)
- [ ] Валидационные данные из других регионов
- [ ] Кросс-валидация по пространству

### 4.3 Типичные ошибки

#### ❌ Недостаточное разнообразие
```python
# Плохо: все эталоны из одного региона
bad_samples = load_samples(region='only_steppe')
# Точность на степи: 0.92
# Точность на предгорье: 0.61  ← плохая генерализация!

# Хорошо: стратифицированная выборка
good_samples = stratified_sampling(
    regions=['steppe', 'forest_steppe', 'foothill', 'valley']
)
# Точность на всех регионах: 0.85-0.89  ← хорошая генерализация!
```

#### ❌ Кластерное распределение
```python
# Плохо: все эталоны рядом
distances = calculate_distances(samples)
mean_distance = 150m  # Слишком близко!
# Результат: пространственная автокорреляция, переобучение

# Хорошо: распределенные эталоны
distances = calculate_distances(samples)
mean_distance = 2500m  # Хорошо разнесены
# Результат: независимые примеры, лучшая генерализация
```

#### ❌ Игнорирование сложных случаев
```python
# Плохо: только простые объекты
samples = select_samples(criteria='easy')  # Только четкие границы
# Результат: плохо работает на реальных данных

# Хорошо: включить сложные случаи
samples = stratified_sampling(
    difficulty=['easy', 'medium', 'hard']
)
# Результат: робастность к различным условиям
```

)

print(f"Финальная точность: {history['best_dice']:.3f}")
